# CVA-VEIL-Auto Sound Setting 1.3.0

**Windows x64 · OBS Studio 33.0.1에서 검증한 미리보기입니다.** 설치 전에 OBS 버전을 확인해 주세요. 설치 EXE와 DLL은 코드 서명이 없습니다.

[Windows 설치 ZIP과 대응 소스](https://github.com/ttaem00/CVA-VEIL-Auto-Sound-Setting/releases/tag/v1.3.0)에서 두 파일과 SHA-256을 확인할 수 있습니다. 릴리스의 대응 소스 ZIP에는 원본 빌드 자료가 포함되어 있습니다.

OBS에서 **소리를 연결하고, 생방송과 녹화에 담을 소리를 고르는** 방송 소리 도우미입니다.
한국어로 시작하며 English·日本語도 선택할 수 있습니다. AllegroMoltoV의
**Loudness Balance Monitor v1.0.2**를 바탕으로 만든 GPL-2.0 수정판입니다.

## 처음 사용할 때

1. Windows 배포 ZIP을 한 폴더에 풀고 동봉한 **설치 시작 파일**을 엽니다.
2. 설치 창의 안내에 따라 OBS를 직접 닫고 **설치하기**를 누릅니다.
3. OBS의 CVA-VEIL 창에서 **채널 설정**을 엽니다.
4. **소리 연결하기 → 어디에 담을까요? → 바뀔 내용 확인** 순서로 진행합니다.
5. 적용 후 짧게 녹화해서 선택한 소리가 들어가는지 들어 봅니다.

목소리는 연결해야 하며 게임·음악은 **사용 안 함**으로 둘 수 있습니다. **여타 소리**는
현재 OBS에 있는 여러 입력을 함께 고를 수 있습니다. 마이크나 앱 소리가 없으면
**소리 추가**에서 연결합니다. 새 소리는 마지막 적용 전까지 초안으로 유지합니다.

## 방송과 녹화에 담을 소리

소리마다 **생방송 / 녹화 영상**을 체크합니다. 현재 배정을 읽어 보여 주며,
음악을 녹화에 넣는 선택도 정상 설정으로 취급합니다. 녹화에서 뺀 소리는 편집용을
포함한 모든 선택 녹화 트랙에서 제외합니다. 포함할 소리는 녹화 메인에 추가하고
기존 편집용 배정은 보존합니다.

마지막 화면은 **모든 오디오 입력**을 계산해 생방송·녹화 포함 목록을 보여 줍니다.
같은 소스를 쓰는 다른 장면에도 배정이 적용됩니다. 음량과 음질 효과는 유지합니다.
중간에 프로필·장면·배정이 바뀌면 현재 값을 덮어쓰지 않고 다시 확인하도록 합니다.

**이전 배정 복원**은 채널 배정을 되돌립니다. 추가한 입력은 다른 장면에서 다시
썼을 수 있으므로 삭제하지 않고, 원래의 출력 없는 상태로 보관합니다. 음량 보정의
**되돌리기**와는 별도 기능입니다.

한 입력에 이미 섞여 들어오는 음악·게임·목소리는 이 화면에서 다시 나눌 수 없습니다.
같은 브라우저의 여러 탭도 함께 잡힐 수 있습니다. 음악 재생과 방송을 듣는 앱은
분리해 사용하세요. 이 설정은 **로컬 녹화**용이며 서버 다시보기 음악 제거 설정이 아닙니다.

## 30초 소리 검사

사용할 소리를 평소 크기로 준비하고 **소리 검사 시작**을 누릅니다. 화면의 큰 초 표시를
보며 **25초 말하기 → 5초 조용히 기다리기**를 진행합니다. 결과를 보고 필요할 때
**추천 설정 적용**을 누르며, 비교 후 직전 음량으로 되돌릴 수 있습니다.

목소리는 최대 ±3dB, 게임·음악은 최대 6dB 낮추는 범위로 제안합니다. 배경음을 자동으로
키우지 않습니다. 방송·녹화·리플레이 버퍼 실행 중에는 변경을 적용하지 않습니다.
여타 소리는 채널 배정 대상이며 자동 음량 보정 대상은 아닙니다. 전문 수치와 용어는
**세부 정보·도움말**에서 확인합니다.

## 현재 검증 범위

검증 대상은 **1.3.0 개발판**입니다. 구현과 실제 실행 확인을 구분합니다.

| 항목 | 상태 |
| --- | --- |
| Windows x64 DLL 빌드·CTest | **PASS — 5/5**. 기존 오디오 검사 4개와 채널 배정 정책 검사 포함 |
| 새 개발 폴더의 도구·SDK | **구성·빌드 확인**. 로컬 캐시 재사용용 공개 빌드 자료 포함 |
| 설치 교체·실패 복구 엔진 | **10개 검사 통과 — PowerShell 5.1/7**. 합성 파일을 이용한 격리 검사 |
| 채널 설정·적용·복원과 실제 MKV | **PASS — 격리 OBS의 16단계·녹화 4개**. 음악 포함·모든 편집 트랙 제외·목소리만 녹화·정확한 복원 확인 |
| 새 화면·표시 언어 | **실제 창 확인 — 격리 OBS**. 소리 연결·전체 입력 표·적용 전 목록, 한국어·English·日本語 전환. 적용 직전 취소 |
| Windows 설치 시작 파일과 창 | **실제 창 확인**. 한국어·English·日本語 전환, OBS 실행 중 설치 잠금 관찰. 전체 설치·권한 승인 흐름은 별도 확인 |
| 실제 사용 중인 OBS 설치·로드 | **PASS**. 공통 설치 처리로 다섯 파일 설치·해시 확인, 재시작 로그의 1.3.0 로드와 기존 소리 설정·트랙 배정 유지 확인 |
| 실제 키보드·화면 낭독기·새 장치/앱 추가·최종 청감 | **미검증**. 공개 화면 동작 호출·합성 소리 검증과 구분 |

1.2.0의 엄격한 음악 단독 무음 검사는 원시 FAIL과 불확정 판정을 역사 기록으로
보존했습니다. 이를 새 1.3 기능의 성공 근거로 바꾸어 사용하지 않습니다. 새 검증은
OBS 33.0.1의 고급 출력·표준 MKV에서 합성 소리로 진행했으며, 녹화 4개의 모든 오디오
트랙을 분석했습니다. 저장 트랙 수는 순서대로 **1·3·3·1개**였고 화면 배정과 일치했습니다.
실제 사용 중인 OBS의 **화면 확인은 미검증**입니다. 설치창에서 시작하는 전체 권한
승인 흐름·실제 방송·단순 출력 녹화·저장 실패 상황·언어별 모든 창의 전체 조작은
위 검증 범위에 포함하지 않습니다.
