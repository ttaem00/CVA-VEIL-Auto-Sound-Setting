# CVA-VEIL-Auto Sound Setting 1.3.0 사용 안내

목소리·게임·음악·여타 소리를 연결하고, 생방송과 녹화 영상에 담을 소리를 고릅니다.
한국어가 기본이며 상단에서 English 또는 日本語를 선택할 수 있습니다. 기술 용어를
읽지 않아도 처음 설정할 수 있도록 단계별로 안내합니다.

## 1. 설치 창에서 시작하기

Windows 배포 ZIP 전체를 한 폴더에 풀고 동봉된 설치 시작 파일을 엽니다.
설치 창에서 파일 확인 결과를 보고 **설치하기**를 누릅니다. OBS가 열려 있으면
방송·녹화를 마친 뒤 직접 닫고 **다시 확인**을 누르세요. 필요한 경우 설치 버튼을
누른 뒤 Windows 권한 안내가 나옵니다.

설치 창은 OBS를 강제로 종료하거나 방송·녹화를 시작하지 않습니다. 기존 소스·음량·
필터·녹화 배정을 바꾸지 않고 플러그인 파일만 설치합니다. 교체 전 파일은 사용자
백업 폴더에 보관하고, 중간 실패 시 이전 파일로 복구합니다. 설치 위치와 오류의
자세한 내용은 접힌 **설치 위치와 세부 정보**에서 확인할 수 있습니다.

설치가 끝나면 **OBS 열기**를 누르고 CVA-VEIL 창의 **채널 설정**을 엽니다.
Windows 설치 시작 파일의 실제 창에서 세 언어 전환과 OBS 실행 중 설치 잠금을
확인했습니다. 전체 설치·권한 승인 흐름은 별도 확인 대상입니다. 명령줄 설치
도우미의 기본 실행은 미리보기입니다.

## 2. 소리 연결하기

소리마다 어디서 들어오는지 고릅니다.

| 이름 | 고를 내용 |
| --- | --- |
| 내 목소리 | 말할 때 사용하는 마이크나 장치 입력. 검사하려면 필요합니다. |
| 게임 | 게임 또는 게임컴 소리. 사용하지 않으면 **사용 안 함**을 고릅니다. |
| 음악 | 노래·BGM을 재생하는 앱의 소리. 사용하지 않아도 검사할 수 있습니다. |
| 방송 듣기 | 돌아오는 방송을 듣는 앱. 생방송·녹화에 다시 들어가지 않게 별도로 관리합니다. |
| 여타 소리 | 알림·다른 앱 등 나머지 입력. 다음 화면에서 여러 개를 고를 수 있습니다. |

같은 입력을 두 역할에 중복 선택할 수 없습니다. 마이크나 앱 소리가 목록에 없으면
**소리 추가**를 누르고 입력 종류·장치/앱·알아보기 쉬운 이름을 고릅니다. 추가한
소리는 초안이며 마지막 **이 설정 적용**을 누르기 전에는 기존 OBS에 만들지 않습니다.
취소하면 초안은 사라지고 기존 연결은 유지됩니다.

앱이 보이지 않으면 먼저 앱을 열고 소리를 재생해 주세요. 같은 브라우저의 여러 탭은
함께 잡힐 수 있으므로 음악과 방송 듣기는 다른 앱을 사용합니다. 게임컴이나 오디오
장치에서 이미 섞여 들어온 음악·게임·목소리는 이 도우미가 다시 분리하지 못합니다.

## 3. 어디에 담을까요?

전체 오디오 입력 목록에서 **생방송 / 녹화 영상**을 체크합니다. 기존 배정을 읽어
보여 주며 새 음악 연결에는 녹화 제외를 제안합니다. 원하는 경우 음악도 녹화에
포함할 수 있습니다. 음악 포함·제외 중 어느 한쪽을 고정 정답으로 판단하지 않습니다.

- **생방송**: 시청자에게 보낼 소리입니다.
- **녹화 영상**: PC에 저장할 녹화에 담을 소리입니다. 방송 사이트의 서버 다시보기 설정이 아닙니다.
- 녹화에서 제외하면 편집용을 포함한 **모든 선택 녹화 트랙**에서 빠집니다.
- 녹화에 포함하면 메인 소리 묶음에 넣고 기존 마이크·게임 편집용 배정은 보존합니다.
- 여타 소리는 여러 개를 선택할 수 있습니다. 배정은 현재 소리를 사용하는 다른 장면에도 적용됩니다.

지원되는 일반 녹화에서는 필요한 녹화 소리 묶음만 준비합니다. 출력 모드·영상 품질·
인코더·방송 트랙은 바꾸지 않습니다. OBS의 ‘방송과 같은 화질’, 무손실, 사용자
FFmpeg 출력 등 지원 준비가 안 된 방식은 적용을 막고 이유를 안내합니다.
이 경우 OBS에서 일반 녹화와 지원 형식을 준비한 뒤 다시 열어 주세요.

## 4. 바뀔 내용 확인과 되돌리기

**바뀔 내용 보기**를 누르면 생방송에 담길 소리, 녹화에 담길 소리, 녹화에서 빠질
소리가 각각 나옵니다. 선택한 대표 입력뿐 아니라 **모든 오디오 입력**을 계산한
목록입니다. 내용을 확인한 뒤 **이 설정 적용**을 누릅니다.

적용 전의 배정과 녹화 선택을 저장합니다. 저장하지 못하면 변경하지 않고, 도중에
실패하면 이전 설정으로 돌립니다. 방송·녹화·리플레이 버퍼 실행 중에는 적용하지
않습니다. 프로필·장면·소스·배정이 중간에 달라지면 현재 값을 덮어쓰지 않습니다.

**이전 배정 복원**은 마지막 채널 설정을 되돌립니다. 같은 프로필·장면·출력 설정과
적용 직후의 소스 배정이 맞을 때만 복원합니다. 새로 만든 입력은 다른 장면에서
재사용했을 수 있으므로 삭제하지 않고 원래의 **출력 없는 상태**로 남깁니다.
이 기능은 아래의 음량 보정 **되돌리기**와 구분됩니다.

적용 후 짧게 녹화해서 직접 들어 보세요. 일반 영상 재생기는 여러 오디오 트랙 중
하나만 재생할 수 있습니다. 편집용 소리를 확인하려면 트랙을 선택할 수 있는 재생기나
영상 편집기를 사용합니다. 개발 검증에서는 아래에 명시한 네 가지 녹화의 모든 오디오
트랙이 화면 배정과 일치했습니다. 개인 PC의 실제 소리는 적용 후 직접 확인해 주세요.

## 5. 30초 소리 검사

1. 사용할 소리를 평소 크기로 준비하고 준비 확인 항목을 체크합니다.
2. **소리 검사 시작**을 누르면 **평소처럼 말해 주세요**와 25초 카운트다운이 나옵니다.
3. **이제 말을 멈춰 주세요**가 나오면 마지막 5초는 조용히 기다립니다. 배경 소리는 그대로 둡니다.
4. **그대로 / 조금 키워요 / 조금 낮춰요 / 추가 확인** 결과를 봅니다.
5. 필요할 때 **추천 설정 적용**을 누르고, 비교 후 **되돌리기**로 직전 음량을 복원합니다.

검사 자체로 음량이 바뀌지는 않습니다. 목소리만 연결해도 검사할 수 있고, 게임·음악은
미사용을 허용합니다. 여타 소리는 방송·녹화 배정 대상이며 자동 음량 보정 대상은 아닙니다.
입력이 없거나 확인 시간이 부족하면 성공으로 표시하지 않고 다음에 할 행동을 안내합니다.

목소리는 최대 **±3dB**, 게임·음악은 최대 **6dB 낮추기**만 제안합니다. 잡음이나 무음에
맞춰 소리를 자동으로 올리지 않습니다. 방송·녹화·리플레이 버퍼가 켜져 있으면 적용을
잠급니다. 충분한 말소리·조용한 구간·출력의 여유를 확인해야 목소리 증폭을 제안합니다.

세부 수치는 **세부 정보**, 용어와 순서는 **도움말**에서 봅니다. LUFS는 구간의 소리
크기를 비교하는 값이며 플랫폼 공식 규격 판정이 아닙니다. 피크는 Sample Peak로
측정하고 True Peak는 측정하지 않습니다. 관측하지 않은 미래 소리나 방 울림의 해결을
보장하지 않으므로 최종 소리는 실제 녹화·방송으로 확인합니다.

## 저장되는 내용과 언어

상단의 언어 선택은 플러그인 표시 언어를 바꾸며 실제 음량·배정을 변경하지 않습니다.
미번역 문구는 한국어 본문으로 대신합니다. 핵심 화면·초기 설정·동적 안내·툴팁·접근성
이름을 같은 번역 카탈로그로 관리합니다. 사용자가 붙인 입력 이름과 실제 앱·장치 이름은
번역하지 않습니다. 설치 창의 언어는 플러그인 언어와 별도로 고릅니다.

플러그인 설정 폴더의 주요 파일은 다음과 같습니다.

```text
%APPDATA%\obs-studio\plugin_config\loudness-balance-monitor\
  assistant.json          대표 입력·참고 목표
  ui-language.json        표시 언어
  channel-state.json      채널 설정의 전후 배정·복원 정보
  last-measurement.json   마지막 검사 수치와 현재 설정 요약
  last-adjustment.json    직전 음량 보정의 전후 값
```

**저장**은 수치와 현재 설정을 저장합니다. 30초 검사는 원시 오디오를 저장하지 않습니다.
이 파일들은 OBS·BRIDGE·Windows 전체 백업을 대신하지 않습니다. 개인 백업과 공개 배포
묶음은 분리하며 방송 키·토큰·쿠키·비공개 브라우저 주소를 포함하지 않습니다.

## 검증 범위

현재 대상은 **1.3.0 개발판**입니다.

- Windows x64 DLL 빌드와 CTest **5/5 PASS**: 기존 오디오 검사 4개와 새 채널 배정 정책 검사.
- 설치 엔진의 격리 검사 **10개**, PowerShell **5.1/7**에서 통과. 파일 교체 중 실패와 복구 포함.
- 격리된 OBS 33.0.1의 화면 동작을 호출해 채널 설정·적용·정확한 복원 등 **16단계를 통과**했습니다. 합성 소리로 저장한 MKV **4개의 모든 오디오 트랙**도 분석해 통과했습니다.
- 음악 제외 시 모든 선택 녹화·편집 트랙에서 빠지고, 포함하면 선택한 트랙에 담기는 것을 확인했습니다. 목소리만 선택한 녹화도 통과했습니다. 네 녹화의 오디오 트랙 수는 **1·3·3·1개**입니다.
- 세 트랙 다음 한 트랙으로 바꿀 때 빈 트랙이 남던 문제를 고친 뒤 같은 네 경우를 다시 검증했습니다. 최종 정상 종료 로그의 메모리 누수 보고는 **0개**였으며, 전체 제품의 누수 감사를 대신하지 않습니다.
- 별도의 격리 OBS 실제 창에서 **소리 연결·전체 입력 표·적용 전 목록**을 확인했고, 목록을 검토한 뒤 적용하지 않고 취소했습니다. 기본 화면의 한국어·English·日本語 전환도 확인했습니다. 모든 번역 문구와 오류 창을 전부 조작한 검사는 아닙니다.
- Windows 설치 시작 파일의 실제 창에서 한국어·English·日本語 전환과 OBS 실행 중 설치 잠금을 확인했습니다. 전체 설치·권한 승인 흐름은 별도 검증 대상입니다.
- **실제 사용 중인 OBS 설치·로드도 통과**했습니다. 공통 설치 처리로 다섯 파일을 설치하고 해시를 확인했습니다. 재시작 로그에서 1.3.0 정상 로드를 확인했으며, 설치 전후 목소리·게임·음악·방송 듣기의 오디오 설정과 트랙 배정은 동일했습니다.
- 녹화 검증은 고급 출력·표준 MKV, 공개 화면 동작 호출, 합성 소리를 사용했습니다. 전체 키보드·화면 낭독기·새 장치/앱 추가·저장 실패·단순 출력 녹화·리플레이 버퍼·실제 방송·언어별 전체 조작·새 설정의 최종 청감은 아직 확인하지 않았습니다. **실제 사용 중인 OBS의 화면 확인은 미검증**입니다. 설치창에서 시작해 권한 승인을 거치는 전체 흐름도 별도 확인 대상입니다.

이전 1.2.0의 엄격한 음악 단독 무음 검사 원시 FAIL은 역사 기록으로 유지합니다.
전환 직후 버퍼 잔여 가능성은 추정이었고 원인을 확정하지 않았습니다. 이를 1.3의
새 채널 설정이나 음악 제외 성공 근거로 대체하지 않습니다. 1.3의 초기 검사 실행 오류와
빈 트랙 문제의 실패 원자료도 보존하고, 수정 후 통과 결과와 구분합니다.
