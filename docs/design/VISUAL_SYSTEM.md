# 시각·문구·상태 기준

- 작은 OBS 창에서 쓰는 데스크톱 도구. 기본 넓이480px, 360px에서도 가로 스크롤·잘린 버튼 없이 검사 동작에 도달해야 한다.
- 바탕 #15191e, 카드 #20262e, 테두리 #343e49. 본문 #f1f4f6, 보조 #b0bac5. 주 동작 #98ead1 바탕에 #102a23 글자. 초점은 #9fc9ff 2px. 색만으로 상태를 알리지 않는다.
- 18px 바깥 여백, 16px 그룹 사이, 12px 행/동작 사이. 카드 모서리12px, 버튼7px. 장식 그림·과한 효과 없음.
- 기본13px, 보조12px, 제목23px, 검사 남은 시간54px. Qt의 DPI 배율과 글꼴 대체를 사용한다. 긴 한국어는 줄바꿈하고 화면을 늘릴 때 여백을 유지한다.
- 클릭 가능한 도움말·세부 정보에 키보드 초점과 Escape/닫기를 제공한다. 툴팁만으로 중요한 안내를 제공하지 않는다. 주요 동작 버튼 높이40px 이상.
- 준비: 입력 세 상태 + 준비 확인 + 시작. 측정: 행동 한 문장/큰 남은 시간/진행 막대/취소. 결과: 행동 가능한 요약 세 줄과 주 동작 적용, 보조 재검사. 적용·원복·취소·저장에는 결과 확인 문구.
- 소리가 없음/측정 준비/연결 없음/지나치게 큰 입력을 구분한다. ‘들어오는 중’은 입력 관찰일 뿐 최적 음량 판정이 아니다.
- 검증은 실제 OBS 표시, 좁은 창 배치, 키보드로 도움말·세부 정보 열기, 검사/적용/원복 회귀와 기존 음량 보존을 포함한다. 정적 스타일 검사로 렌더 성공을 주장하지 않는다.
