# 1.3 개선 계획 — 처음 연결하고 녹화할 소리 고르기

목표: 음향을 모르는 사람이 한국어 안내만으로 목소리·게임·음악·여타 소리를 연결하고, 생방송과 로컬 녹화에 담길 소리를 고른 뒤 바뀔 내용을 확인하고 되돌릴 수 있게 한다. D 드라이브의 이 저장소가 새 개발 정본이다.

## 사용자 흐름과 범위

1. 기본 화면의 **채널 설정**에서 시작한다. ‘채널’은 서비스 방송 채널과 헷갈리지 않도록 첫 화면에서 **소리 나누기**로 설명한다.
2. **소리 연결하기**: OBS에 있는 입력을 역할에 연결한다. 목소리·게임·음악은 별개로 선택하고, 여타 소리는 여러 개를 고를 수 있다. 방송을 듣는 앱은 별개로 유지한다. 같은 입력을 여러 역할에 중복 선택하지 못한다. 필요한 경우 Windows 마이크/앱 소리를 새로 만들 수 있는 짧은 추가 흐름을 제공한다.
3. **어디에 담을까요?**: 소리마다 ‘생방송’, ‘녹화 영상’ 체크박스로 선택한다. 처음 연결하는 음악은 생방송 포함/녹화 제외를 제안하되 기존 사용자의 선택은 읽어 보여 준다. 서버 다시보기 설정과 로컬 녹화를 혼동하지 않는다.
4. **바뀔 내용 확인**: 녹화에 들어갈 것/빠질 것을 쉬운 이름으로 보여 준다. 원래 배정과 녹화 선택을 저장한 뒤 적용한다. 소스 배정은 다른 장면에서 같은 소스를 써도 영향을 준다는 점을 짧게 알린다.
5. **완료/되돌리기**: 적용한 값을 API로 다시 확인한다. 설정이 중간에 바뀌었으면 덮어쓰지 않고 다시 확인하도록 한다. 방송/녹화/리플레이 중 적용하지 않는다. 방송을 임의로 중단하지 않는다.

## 구현과 경계

- OBS 공식 API로 현재 소스/UUID/음소거/오디오 비트마스크/프로필 출력을 읽는다. 프로필/장면이 바뀌거나 이전 배정과 다르면 적용 중단.
- 기존 선택된 방송 트랙은 바꾸지 않는다. 지원되는 일반 녹화에서 RecTracks만 필요시 준비하고 공식 config API로 안전 저장한다. 출력 모드·인코더 선택·영상 품질·서비스/VOD를 임의 변경하지 않는다. 고급 출력·표준 MKV의 실제 시험 녹화로 선택 반영을 확인했다. 세 트랙에서 한 트랙으로 줄일 때 OBS 33.0.1에 빈 트랙이 남던 문제는 실행 중이지 않은 출력의 뒤쪽 인코더 연결을 공식 API로 정리해 수정했다.
- 음악 등 녹화 제외 입력은 녹화 메인뿐 아니라 선택된 **전체 녹화 트랙**에서 뺀다. 포함할 입력은 녹화 메인에 넣고 기존 편집용 배정은 보존한다. 방송/녹화 비트가 겹치면 별도의 녹화 메인을 준비하고 요약한다.
- Simple의 ‘방송과 같은 화질’, FLV/무손실/사용자 FFmpeg 등 분리 불가능하거나 아직 검증하지 않은 방식은 성공으로 표시하지 않는다. 지원되는 녹화 선택으로 준비하는 짧은 안내와 명확한 차단 이유를 제공한다.
- 새 앱/장치 입력은 OBS가 제공하는 속성 목록에서 선택한다. Windows 설정이나 하드웨어 드라이버를 임의 변경하지 않는다. 이미 캡처 중인 같은 앱/전체 PC 소리의 중복 가능성을 안내하고 자동 삭제하지 않는다.
- 현재 측정 코어·음량·필터를 변경하지 않는다. 새 여타 입력은 방송/녹화 배정 대상이며 자동 음량 보정 대상으로 오해시키지 않는다.
- 인증·브라우저 URL·토큰·전체 사용자 설정은 저장하거나 묶지 않는다. 롤백에는 필요한 UUID/배정/녹화 선택만 기록한다.

## 언어와 설치

- 한국어 기본, English·日本語 선택. 기존 사용자의 OBS 언어와 별도로 플러그인 표시 언어를 저장한다. 핵심 화면·초기 설정·경고·툴팁·설치 UI에 같은 언어 체계를 적용한다. 미번역 키가 화면에 표시되지 않도록 한국어로 대체한다.
- 설치는 Windows의 창으로 ‘설치 위치 확인 → 설치 → OBS에서 시작’ 흐름을 제공한다. OBS 실행 중에는 설치를 막고 종료 후 다시 확인하게 한다. 프로세스를 임의 종료하지 않는다.
- 기존 스크립트 설치/미리보기는 유지하되, 일반 사용자는 터미널을 열지 않고 시작하도록 한다. 파일 검증, 이전 플러그인 백업, 실패 시 복구, 완료 후 폴더/도움말 진입을 제공한다. 네트워크 다운로드나 인증은 필요하지 않다.

## 설계와 검증

기존 DESIGN.md와 VISUAL_SYSTEM.md의 색·여백·대비·짧은 문구를 유지한다. 이전에 실제 확인한 Dribbble/Behance 컨셉 화면의 역할별 정렬과 정보 위계를 재사용한다. 안내는 한 단계에 한 행동, 기술 정보는 접기/도움말로 보낸다.

현재 상태: 별도 에이전트의 적대적 검토에서 수락한 직접 실패 다섯 개를 구현에 반영했다. 상세는 [ADVERSARIAL-1.3.md](ADVERSARIAL-1.3.md). 목소리는 필수, 게임·음악은 미사용을 허용한다. 여타 입력을 포함한 모든 실제 소리의 최종 녹화 포함 목록을 계산한다. 새 입력은 마지막 적용 전까지 초안으로 유지한다. 언어 변경은 음향 상태 판단에 영향을 주지 않는다. 외부 공개/업로드는 범위 밖이다.
