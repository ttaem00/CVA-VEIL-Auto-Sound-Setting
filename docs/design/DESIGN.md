# CVA-VEIL-Auto Sound Setting 화면 기준

본질 목표: 음향 지식 없이 입력 여부를 확인하고 30초 검사·추천 적용·되돌리기를 사용할 수 있어야 한다. 수치 이해는 시작 조건이 아니다. 긴 안내를 읽게 만드는 원인은 모든 정보를 같은 화면과 무게로 제공한 데 있다.

시각 기준은 [VISUAL_SYSTEM.md](VISUAL_SYSTEM.md)를 함께 적용한다.

- 기본 화면은 세 입력 행, 현재 해야 할 행동 하나, 검사 시작 버튼을 중심으로 한다. 수치·소스·참고 기준은 별도 세부 정보, 한계와 용어는 도움말/툴팁에서 제공한다.
- 검사 단계는 말하기 25초 → 조용히 5초. 남은 초를 크게 표시하고 할 일은 한 문장으로 바뀐다. 퍼센트와 경과초를 중복 노출하지 않는다.
- 준비 확인·잠김 이유·입력 부족·원복 충돌은 실행에 필요한 정보이므로 기본 화면에서 짧게 알린다. 위험한 실패를 도움말에만 숨기지 않는다.
- 적용 전의 음량을 보존한다. 전문가 수치가 없더라도 입력/측정/권한 부족을 정상으로 표시하지 않는다.

2026-11-09에 브라우저 화면을 실제 확인한 참고 자료:

1. [Kron Raufi / Loka의 Dark Mode Music Studio](https://dribbble.com/shots/26615537-Dark-Mode-Music-Studio-UI-Design): 같은 행 안의 역할·조작·신호 정렬을 참고. 타임라인 편집기와 낮은 대비의 장식은 도입하지 않음.
2. [Jang Trịnh의 Mobile Dashboard](https://www.behance.net/gallery/51204899/Mobile-Dashboard-w-Real-Data-Dark-theme-UI): 주요 값의 크기 차이와 그룹 간 여백을 참고. 장식 그래프·입체 기기·다색 차트는 도입하지 않음.

두 자료는 디자이너가 게시한 컨셉 이미지이며 실제 제품의 사용성·접근성 검증 자료가 아니다. 이미지/아이콘/코드/브랜드 조형은 복사하지 않는다. 제품은 기존 Qt 위젯과 자체 배치로 구현한다.

사용자 목표: 방송과 음악 없는 녹화에서 목소리가 잘 들리고 게임·음악 균형이 적절한지 확인하고, 안전한 범위에서 비교·적용·복원한다.

- OBS 도크에서 현재 방송/녹화 실제 트랙과 마이크/게임/음악을 구분한다. 측정 대상과 값이 유효한 구간을 명시한다.
- 무음·발화대기·데이터부족·소스없음은 실패 판정 대신 이유와 회복 방법을 표시한다.
- 주 동작은 30초 소리 확인. 측정→제안 비교→적용→원복 흐름. 라이브 중에는 원치 않는 변경을 하지 않는다.
- 자동 적용은 사용자 실행으로만, 변경량 제한과 변경 전 값 보존. 침묵/잡음을 따라 게인을 올리지 않는다.
- 한국어 평문 중심. 색상과 함께 구체적인 텍스트, 단위, 수치 근거를 제공한다.
- 목표값은 사용자 참고값이며 플랫폼 공식규격으로 표현하지 않는다. LUFS와 sample peak를 구분하고 true peak 미지원 명시.
- 소스 이름을 바꾸거나 음악 제외 녹화 정책을 무시하지 않는다. 인증·URL·방송키는 읽거나 내보내지 않는다.
- 작업 중·대기·불충분·오류·완료·비활성 상태를 분명히 하고 취소와 원복을 제공한다.
