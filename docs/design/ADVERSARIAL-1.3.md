# 1.3 적대적 검토와 수락 조건

2026-11-09. 사용자의 명시 요청으로 별도 에이전트가 계획과 기존 코드를 읽기 전용으로 검토했다. 목표는 초보자가 소리 연결·방송/녹화 선택·설치·언어 선택을 처리하고 기존 설정을 보존하는 것이다. 추측성 방어 연쇄를 제외하고 정상 사용의 직접 실패 다섯 개만 검토했다.

| 원래 문제와 직접 실패 경로 | 판단 | 반영할 수락 조건 |
| --- | --- | --- |
| 새 녹화 선택에 미관리 알림/모니터링 입력이 이미 배정돼 원치 않는 소리가 저장됨 | blocker 수락 | 모든 오디오 입력의 적용 후 배정으로 최종 포함 목록을 계산. 소스별 방송/녹화 체크를 명시. VOD 충돌 방지. |
| 음악 녹화 포함·게임 제외가 기존 고정 정답과 충돌하고, 음악 미사용자는 검사 불가 | blocker 수락 | 상태를 실제 선택으로 계산. 목소리 필수, 게임/음악 선택 사항. 보정/원복은 선택된 입력 수 대응. |
| 새 소스 추가 후 취소에 찌꺼기가 남거나 다른 프로필에 원복 적용 | blocker 수락 | 새 소스는 마지막 적용 전까지 초안. 이력에 프로필/장면/방송·녹화선택/UUID/전후 배정을 저장하고 변경 충돌 시 거부. 저장 실패에 실제 변경 없음. |
| 설치 중 일부 파일 복사 실패로 DLL/번역 버전이 섞임 | blocker 수락 | 사전 권한/파일 검사, 사용자 경로 백업, 준비 후 교체, 실패 시 원복. 격리 폴더에서 실패를 주입해 검증. |
| 언어 파일만 추가하고 동적 경고·추천이 한국어로 남거나 문장 비교로 상태가 달라짐 | blocker 수락 | 동일 번역 API를 기본/설정/동적 상태/접근성/툴팁에 적용. 상태는 enum/값으로 판단. 언어별 정상·빈·잠김·오류 확인. |

‘미사용’은 고장과 다르게 표시한다. 여타 소리는 여러 개를 다루되 자동 음량 보정 범위와 구분한다. 기존 전체PC/하드웨어 믹스/같은 브라우저 앱에 섞인 소리는 분리됐다고 보장하지 않는다.

검토 결과는 구현 전에 계획에 반영했으며 동일한 약한 가정을 반복하는 추가 검토는 하지 않는다. 다음은 구현 후 직접 확인한 근거와 남은 한계다. 구현 완료와 모든 사용 상황의 검증 완료를 같은 뜻으로 사용하지 않는다.

| 원치 않는 입력이 녹화에 포함됨 | 전체 입력의 적용 전 목록을 실제 격리 창에서 확인. 별도 녹화 검증에서 음악을 모든 선택 편집 트랙에서 제외하고, 방송 듣기·여타 소리 제외 결과도 합성 소리로 확인 | 개인 장치의 실제 소리·실제 방송 경로 |
| 고정된 음악 제외 정답·필수 게임/음악 | 음악 포함·제외, 목소리만 선택한 실제 MKV 검증 통과. 실제 창에서 선택 변경과 목록 확인 | 선택 입력 수별 실제 마이크 음량 보정 청감 |

| 설치 파일 버전 혼합 | 다섯 파일을 관리하는 공통 교체 엔진의 실패 주입·복구 포함 10개 검사, PowerShell 5.1/7 통과. 실제 설치 창에서 OBS 실행 잠금과 세 언어 확인. 운영 설치의 다섯 파일 해시·1.3.0 정상 로드·기존 오디오 설정 유지 확인 | 실제 권한 승인·설치창에서 시작하는 전체 흐름, 운영 OBS 화면 확인 |
| 번역 누락·언어별 상태 변경 | 한국어 기본·English·日本語 공통 번역 API와 한국어 대체 구현. 별도 실제 창에서 기본 화면의 정적·동적 언어 전환 확인 | 모든 번역 창·빈 상태·잠김·오류의 전수 화면 확인, 전체 키보드·화면 낭독기 |

## 최종 검증 근거와 범위

1.3.0 DLL SHA256은 `5222fc14648f45ecdef110e4fb6c22c53f1e6bcb2e618324ab93c45433fd1a39`이다. 격리 OBS 33.0.1에서 공개 화면 동작 **16단계**와 실제 MKV **4개 전체 AAC 트랙 분석**을 통과했다. 트랙 수는 **1·3·3·1개**이며 음악 포함·전체 선택 트랙 제외·목소리만 녹화·정확한 원복을 확인했다. 별도 실제 창 관찰은 소리 연결·전체 입력 표·적용 전 목록을 확인한 뒤 적용하지 않고 취소했으며 기본 화면의 한국어·English·日本語 전환을 확인했다.

초기 실행의 import 오류와 세 트랙에서 한 트랙으로 줄일 때 빈 트랙 두 개가 남던 실패는 원자료로 보존했다. 실행 중이지 않은 출력의 뒤쪽 인코더 연결을 공식 API로 정리한 뒤 같은 네 경우를 다시 검사해 통과했다. 최종 정상 종료의 누수 보고는 0개였으나 전체 제품의 누수 감사로 해석하지 않는다.

근거: `fixture-summary.json`, `fixture-result.json`, 녹화별 네 개의 `*-encoded-analysis.json`, `visual-1.3-observation.json`. 녹화는 합성 소리와 고급 출력·표준 MKV를 사용했다. 단순 출력·리플레이 버퍼·실제 방송·실제 운영 OBS 시각검증을 포함하지 않는다. 별도로 **운영 설치·다섯 파일 해시·1.3.0 정상 로드·기존 오디오 설정과 트랙 배정 유지 확인은 통과**했다. 근거는 `production-1.3-install-receipt.json`과 `production-1.3-observation.json`이다. 운영 OBS의 화면 확인·최종 개인 청감·권한 승인·전체 키보드·화면 낭독기 사용은 미검증이다. 이번 검토는 이 한계를 숨기거나 공개 배포 가능 판정을 대신하지 않는다.
